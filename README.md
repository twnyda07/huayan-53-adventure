# 善財童子五十三參 ‧ 奇幻冒險

把《華嚴經 ‧ 入法界品》**善財童子五十三參**，改編成 53 篇適合小學生的奇幻冒險故事網站。
跟著善財童子向南參訪 53 位老師，收下 53 份人生的禮物——每一篇都連結一項聯合國永續發展目標（SDGs）。

> 寶嚴禪寺 ‧ 兒童生命教育系列

---

## 🌟 特色

- **53 個不重覆的核心價值**，橫跨自我管理、人際相處、知識技藝、自然萬物、生命真理，完整涵括宇宙人生的道理。
- **兩條貫穿全系列的隱藏線**：
  - 👦✨ **五髻少年**——文殊菩薩的化身，每一參悄悄現身、點一句話就消失，供小讀者一路解謎。
  - 🦁🐉🐕🐘 **四大吉祥神獸**——善知獅（智）、辨色龍（悲）、諦聽犬（願）、曉非象（行），代表菩薩道的「悲智願行」四德。牠們隱藏、不定時現身，只在善財突破困境或行善時登場相助，事成後加入求法隊伍成為夥伴；小讀者可一路隱藏收集，四德齊備即見普賢。
- 每篇附 **尾聲小卡**（想一想、SDGs 行動、隱藏解謎、認識一個詞）與**兒童劇劇本**。
- 純靜態網站，手機、平板、電腦皆可閱讀。

## 📖 線上閱讀

以 GitHub Pages 發布後，網址類似：`https://<你的帳號>.github.io/<repo 名稱>/`

## 🗂 檔案結構

```
sudhana-53-web/
├── index.html          # 首頁：旅程地圖（53 站）
├── stories/
│   ├── 01.html         # 第一參 ‧ 德雲比丘〈追不到的山頂〉
│   └── 02.html         # 第二參 ‧ 海雲比丘〈會說話的大海〉
├── assets/
│   ├── style.css       # 樣式
│   └── app.js          # 首頁旅程地圖產生器
├── data/
│   └── catalog.js      # 全 53 參目錄（標題、主題、SDG、上架狀態）
└── README.md
```

## ➕ 新增一篇故事

1. 依現有 `stories/01.html` 的版型，新增 `stories/NN.html`。
2. 打開 `data/catalog.js`，把對應那一參的 `status` 改為 `"ready"`，並補上 `href: "stories/NN.html"`。
3. 首頁的旅程地圖會自動把它變成可點閱讀。
